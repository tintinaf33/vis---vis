Vis-à-vis

Collez la configuration de deux équipements voisins. L’outil retrouve les liens qui les relient, puis vérifie paramètre par paramètre que chaque côté attend exactement ce que l’autre envoie : adressage, MTU, VLAN, agrégats LACP, OSPF, IS-IS, LDP et sessions BGP.

Analyse faite dans votre navigateur : aucune configuration n’est envoyée nulle part.

BÉquipement voisin

Collez une configuration ou ouvrez un fichier.

Formats acceptés : Junos en hiérarchique ou en display set (lignes désactivées ignorées, routing-instances prises en compte) et Comware 7 (display current-configuration, noms d’interfaces complets ou abrégés).

Code source, ajout de constructeurs et hébergement : voir le README du dépôt.

Les clés Junos $9$ sont décodées localement uniquement pour être comparées et ne sont jamais affichées. Les clés HPE $c$ ne sont pas réversibles et restent à vérifier à la main.
